# Sfida $100 — motore di simulazione (paper trading)

Simulazione di trading con prezzi reali OKX: nessun ordine reale, nessun denaro reale.
GitHub Actions esegue il motore ogni 5 minuti (`gh_run.py`). Stato e risultati restano nei canali Telegram privati della sfida, non in questo repository.

Unico segreto richiesto: `TELEGRAM_BOT_TOKEN` (Settings → Secrets and variables → Actions).
